How to build your own

Table tab

Every stored row is one institution, one fiscal year and one measure. The table adds rows up, so set it up in this order:

  1. Measure first. Pick one measure, such as All R&D or Department of Energy. Adding up rows from different measures counts the same dollars twice. To compare several measures, pick Every Federal agency measure (or every field) and put measure in Rows or Columns.
  2. Rows is what runs down the side. Use then by to nest a second or third level, such as sector then state. Each level gets a subtotal; click a row to collapse it.
  3. Columns is what runs across, usually year. Choose (none) for one total column.
  4. More settings opens the full panel. Drag fields from All Columns into Group By, Split By or Where. Use Where to filter, for example state == ID. Use the export button above the table to download the current view as CSV.

Try these, then look at the dropdowns to see how each one is set up:

  • Idaho institutions, every year
  • Institution type, then state
  • Each federal agency by institution type, FY 2024
  • R1 universities' federal funding, by agency

Chart builder tab

Each row is one institution in one fiscal year. Every measure is its own field, in whole dollars (NCSES publishes thousands; HERD Explorer multiplies by 1,000). Axes read k, M and B for thousands, millions and billions. The example buttons above the chart builder open ready-made charts you can change; drag a field off a shelf to remove it.

  1. Drag year to the X axis and a measure, such as Source of funds: All R&D, to the Y axis. Measures are summed.
  2. Drag sector or state to Color for one line or bar per group.
  3. Drag a field to Filters to narrow the data, for example state to just Idaho.
  4. Change the mark type in the toolbar: bar, line, area, point, or table. Transpose swaps the axes.
  5. Use the + next to the chart tabs to start a new chart; your other charts stay open.

For tables grouped by several fields with subtotals, or for comparing many measures at once, the Table tab is easier.

Source: NCSES HERD Survey public microdata, FY 2012-2024, nominal dollars. Institution type (sector) from the 2021 Carnegie Classification. Measures marked "standard form" cover institutions with $1 million or more in R&D; see About HERD for every definition.
